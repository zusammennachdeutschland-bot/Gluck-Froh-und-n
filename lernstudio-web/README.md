# Glück Lernstudio Web + Homework System

A standalone, web-based extraction and extension of the **Glück Lernstudio** module, deployable to **Vercel** with an integrated, zero-account **Homework assignment** & **Teacher Cockpit** system.

---

## 🌟 Key Features

1. **Full Lernstudio Web App**
   - 100% feature parity with the desktop Glück Lernstudio.
   - All **35 Interactive Games** (Memory, Balloon Pop, Sorting, Ultimate XO, Sentence Builder, Space Defense, Whack-a-Mole, Submarine, Race, Wheel, Robot Repair, etc.).
   - German vocabulary sets with native TTS audio pronunciation (Normal 1.0x & Slow 0.6x).
   - Dynamic theme engine (Pastel, Cyber, Nature, Sunset, Cosmos, Candy).
   - Team mode and individual play.

2. **Blooket-Style Homework System (`/homework/:id`)**
   - Zero registration / zero login friction for students.
   - Students enter their name and solve focused vocabulary challenges.
   - Built-in German audio speech with 1.0x and 0.6x slow speed support.
   - Immediate feedback and celebratory completion animations.
   - Real-time submission recording with anti-cheat server-side scoring.

3. **Teacher Cockpit (`/teacher`)**
   - Protected by server-side `TEACHER_PASSWORD` and secure HttpOnly HMAC cookie sessions.
   - Create assignments in seconds with Set snapshots (ensures future set modifications never corrupt existing homework).
   - Configure question count, maximum attempts per student, and optional deadlines.
   - Instant 1-click shareable URLs (`https://<your-domain>/homework/<id>`).
   - Detailed participation analytics:
     - Real-time submission count and average accuracy.
     - Hardest words breakdown (identifies which vocabulary items challenged students most).
     - Individual student scorecards and timestamps.
     - **1-Click CSV Export** for gradebooks and progress reports.
     - Close or re-open assignments at will.

## 🚀 Deployment to Vercel

### Step 1: Push or Link Repository to Vercel

When creating a new project in Vercel:
1. Set the **Root Directory** to `lernstudio-web`.
2. Framework Preset: **Vite**.
3. Build Command: `npm run build` (or leave default).
4. Output Directory: `dist` (or leave default).

### Step 2: Configure Vercel Blob Storage

The homework system uses **Vercel Blob** for atomic, partition-safe JSON persistence (separate blobs for assignments and submissions to guarantee zero race conditions).

1. In your Vercel Project Dashboard, navigate to the **Storage** tab.
2. Click **Create Database** and select **Blob**.
3. Link the Blob store to your project.
4. Vercel automatically populates the `BLOB_READ_WRITE_TOKEN` environment variable.

### Step 3: Set Environment Variables

In your Vercel Project Settings > **Environment Variables**, configure:

| Variable | Description | Example |
| :--- | :--- | :--- |
| `BLOB_READ_WRITE_TOKEN` | Generated by Vercel Blob store | `vercel_blob_rw_...` |
| `TEACHER_PASSWORD` | Password to access `/teacher` dashboard | `MeinSuperGeheimesPasswort123` |
| `SESSION_SECRET` | Secret key for HMAC cookie signing | `random_32_char_hex_or_passphrase` |

## 💻 Local Development

Run the web application locally:

```bash
cd lernstudio-web
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

- **Lernstudio Web**: `http://localhost:3000/`
- **Teacher Cockpit**: `http://localhost:3000/teacher` (Default dev password: `glueck-teacher-2026`)
- **Student Homework**: `http://localhost:3000/homework/<assignment-id>`

## 🔒 Security & Data Integrity

- **Server-Side Grading**: Student submissions only pass selected answers; the server grades responses against the `setSnapshot` stored inside the assignment blob.
- **Zero Race Conditions**: Each submission is stored in its own partition `submissions/{assignmentId}/{submissionId}.json`, eliminating lock contention and data loss when multiple students submit simultaneously.
- **Tamper-Proof Sessions**: Teacher sessions use SHA-256 HMAC tokens stored in `SameSite=Strict`, `HttpOnly`, `Secure` cookies.
